허브의 도구와 자료 탭에서 타이핑 워크북을 열고 프로젝트를 고르세요. 각 프로젝트의 starter.py를 직접 완성한 뒤, 정말 막힌 함수만 solution.py와 비교합니다.

텍스트 전처리

정규화, 토큰 경계, 데이터 계약을 직접 구현합니다.

  • 입력 예시를 손으로 적기
  • 예외 조건까지 실행하기

의도 분류

  • accuracy와 macro F1 비교
  • 오분류 한 건 설명하기

의미 검색

벡터화, 유사도, top-k 검색을 조립합니다.

  • 검색 점수와 관련성 비교
  • top-k 변화 확인

프레임워크 없는 RAG

문서 로드, 검색, grounded prompt를 직접 잇습니다.

  • 근거 문서 먼저 보기
  • 보류 기준 적기

LangChain RAG

문서, 청크, retriever 경계를 의식하며 조립합니다.

  • metadata 유지하기
  • 로컬 fallback 확인

RAG 평가

Hit@k, Recall@k, MRR, coverage를 분리해 계산합니다.

  • 분모를 먼저 적기
  • 실패 사례 찾아보기
