안전한 기본 원칙
허브가 만든 learner_work의 개인 starter.py에서만 코드를 고칩니다. 원본과 정답 파일 solution.py는 닫아 두고, 막혔을 때만 같은 함수 이름을 찾아 비교한 뒤 다시 직접 입력하세요.

함수·클래스가 낯설다면 함수·API 한국어 사전에서 입력, 반환값, 주의점과 배경 용어를 먼저 확인하세요.

한 프로젝트를 끝내는 순서

  1. 허브에서 프로젝트를 선택합니다.도구와 자료 탭의 타이핑 프로젝트에서 starter.py를 엽니다.
  2. TODO 하나만 고릅니다.처음에는 가장 위에 있는 함수 하나만 구현합니다.
  3. 직접 타이핑하고 저장합니다.코드 블록을 복사하지 말고 함수의 입력과 반환값을 보며 적습니다.
  4. 즉시 실행합니다.아래 명령으로 지금 만든 코드가 어디까지 동작하는지 확인합니다.
  5. 출력 한 줄을 기록합니다.오류, shape, metric, 검색 결과 중 하나를 적고 다음 수정 하나를 결정합니다.

공통 실행 명령

프로젝트 최상위 폴더에서 실행합니다. 프로젝트 번호와 폴더 이름만 바꾸면 됩니다.

.\.venv\Scripts\python.exe projects\nlp\01_text_preprocessing\starter.py
